# Writer's Block Community and Newsletter Design

## Goal

Launch a branded Italus Community gateway, connect each discussion card to its own Beehiiv Community channel, and preserve the approved author-first Writer's Block newsletter as a reusable monthly template.

## Beehiiv Community

- Community name: `The Writer's Room by Italus Studio`.
- Access: free for newsletter subscribers during the initial launch.
- Do not invite members during setup.
- Sync published newsletter web posts into Beehiiv Community when the setup flow supports it.
- Start with direct messaging disabled for safer moderation.
- Create these four discussions:
  - `Writer's Room`: each Writer's Block issue and its creative question.
  - `Italus Bookshelf`: influential books, research, reviews, and reading notes.
  - `Manuscript Lab`: excerpts, revision choices, continuity, and prose craft.
  - `Worlds & Characters`: character motives, lore, factions, settings, and canon.

## Italus Community Page

- Add `Community` between `Pricing` and `Social` in every primary navigation.
- Add a branded `community.html` gateway using the established dark studio, parchment, and antique-gold visual language.
- The page has a main `Enter the Writer's Room` call to action and four discussion cards.
- Each card opens its matching Beehiiv Community channel; links must not be generic placeholders.
- Add Community to the footer and sitemap.
- Use the Italus tree medallion and the clean studio artwork supplied by the user.

## Writer's Block Monthly Template

- Preserve the approved masthead, warm studio artwork, tree medallion placement, parchment body, and antique-gold accents.
- Do not use purple text or purple controls.
- Keep the personal Italus letter first with `What we learned at the writing desk` and `From the studio, with ink still wet.`
- Include reusable sections for the personal note, Italus Bookshelf, excerpt, character/worldbuilding spotlight, craft lesson, community discussion, and closing note.
- The community call to action opens the main Writer's Room feed.
- Save changes to the existing `Writer's Block - Monthly Issue` template only. Do not publish a newsletter or invite subscribers.

## Release

- Run the static-site tests and inspect the new page at desktop and mobile widths.
- Commit and push the website changes to the existing GitHub repository.
- Verify the production deployment and the final community links on `italusbooks.com`.
